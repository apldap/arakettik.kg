Добавить возможность

Вставьте объявление, проверьте поля и посмотрите карточку. Всё сохраняется на этом устройстве. Для публикации скачайте manual-content.js и замените им одноимённый файл существующего сайта на GitHub.

Начать с текста объявления

Можно вставить обычный пост: первая строка станет названием, остальное — описанием. Подписанные поля, как в примере, заполняются автоматически. Это простой разбор текста, без ИИ.

Используйте смещение на дату закрытия: летнее и зимнее время могут отличаться. После дедлайна карточка исчезнет сама. Возможности без подтверждённого срока добавляй после уточнения у организатора.

Картинка сохраняется без изменения. Для быстрого сайта выбирайте исходный файл разумного размера; максимум 3 МБ.
