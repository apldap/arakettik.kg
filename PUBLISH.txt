Обновление существующего сайта ARAKETTIK

1. Распакуйте архив.
2. В существующем репозитории GitHub откройте папку, в которой находится index.html.
3. Через Add file → Upload files загрузите файлы из архива вместе с папкой assets, заменяя одноимённые файлы.
4. Нажмите Commit changes и дождитесь успешного обновления GitHub Pages.
5. Откройте сайт и обновите страницу.

Это пакет готовых файлов, а не подтверждение публикации в интернете. Новый репозиторий создавать не требуется. Редактор мероприятий остаётся доступен по пути editor.html.
